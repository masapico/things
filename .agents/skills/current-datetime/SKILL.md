# Current DateTime

このスキルは現在の日時を取得するために使用します。

## 使い方

ユーザーが「今何時？」「今日の日付は？」「現在日時を教えて」などと尋ねたときにこのスキルを呼び出します。

## 実行内容

1. `date` コマンドまたは `Date` オブジェクトを使用して現在日時を取得します。
2. 結果をユーザーにわかりやすく日本語で表示します。
3. 必要に応じて、以下のフォーマットで表示できます：
   - 日付のみ: `YYYY-MM-DD`
   - 時刻のみ: `HH:MM:SS`
   - 日時: `YYYY-MM-DD HH:MM:SS`
   - タイムゾーン付き: `YYYY-MM-DD HH:MM:SS TZ`
