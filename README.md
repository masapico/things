# things

## 使う時
- リポジトリの /pocketbase をコピー
- pocketbase実行ファイルをダウンロード
- pocketbaseの実行ファイルを /pocketbase に持っていく

- pocketbase　起動コマンド
  - ./pocketbase create superuser <mail> <password>
- http://localhost:8090/_/ へアクセスし、作成した superuser でログイン1
- userを作成
  - mail, password, name を入力して作成 →　このユーザーでアプリにログインする
